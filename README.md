# Dayflow — персональная система планирования

Dayflow — русскоязычное local-first PWA-приложение для задач, календаря, целей, привычек и личного планирования. Проект не использует ИИ и не содержит отдельного режима концентрации. Pomodoro — самостоятельный настраиваемый таймер.

## Запуск

Для локального запуска нужен Node.js или Python.

**Python**

```bash
python -m http.server 8080
```

**Windows:** можно запустить `run-dayflow.bat` двойным щелчком. Скрипт поднимет локальный сервер на порту 8080; окно нужно оставить открытым.

**Node.js**

```bash
npx serve .
```

Откройте `http://localhost:8080` (для Python) или адрес, который покажет `serve`.

Для установки PWA и Service Worker нужен `localhost` или HTTPS. Для iPhone откройте HTTPS-адрес в Safari и используйте «Поделиться» → «На экран Домой». На Windows приложение можно установить из поддерживаемого браузера.

## Реализовано

- Главная панель с переставляемыми и скрываемыми виджетами, ежедневным фокусом и быстрыми действиями.
- Задачи: списки, несколько списков у одной задачи, приоритеты, статусы, дата и дедлайн, повторения (день/будни/неделя/месяц), подзадачи одного уровня, теги, папка заметки, форматированные заметки с таблицами/чек-листами/ссылками/изображениями и встроенными/пользовательскими шаблонами, вложения и связи с целями.
- Календарь: день, 3 дня, неделя, месяц, год и agenda; события, задачи и привычки; события на весь день; свайп смены периода на сенсорных экранах; перенос перетаскиванием с сохранением длительности события и дедлайна задачи.
- Цели: сферы жизни, числовой прогресс, прогресс по задачам/привычкам/этапам и смешанный прогресс; связанные задачи и привычки; этапы; активные, завершённые и отложенные цели.
- Привычки: бинарные, количественные, длительность и недельная норма; дни недели или интервал; частичные отметки; история, серии и heatmap.
- Быстрое добавление с правиловым разбором русских дат, дней недели и времени (без ИИ).
- Поиск по названиям, описаниям, тегам, папкам заметок и спискам; фильтры `type:`, `tag:`, `list:`, `priority:`, `status:` и `date:`, история запросов и быстрые переходы к результатам.
- Аналитика по задачам, привычкам, целям, времени, календарю и сферам жизни; сравнение периодов, недельный обзор, планирование недели и оценка загруженности.
- Настраиваемый Pomodoro, утренний и вечерний обзоры.
- Архив и корзина с восстановлением и окончательным удалением.
- Настройки темы (системная/светлая/тёмная), акцентного цвета, плотности, форматов даты и времени, начала недели, виджетов, Pomodoro, обзоров, уведомлений и тихих часов. Напоминание о просрочке задачи отправляется однократно.
- Экспорт/импорт полной резервной копии JSON; экспорт задач и аналитики CSV (открывается в Excel); импорт задач CSV; экспорт/импорт календарных событий ICS; импорт показателей и тренировок из Apple Health XML; печать в PDF.
- Локальная база IndexedDB, резервный fallback на localStorage, адаптивная компоновка для iPhone и Windows, manifest и офлайн-кэш оболочки через Service Worker.

## Хранение и приватность

Данные хранятся локально в браузере на конкретном устройстве. Они не синхронизируются между iPhone и Windows и не отправляются на сервер. Рекомендуется периодически скачивать JSON-резервную копию.

Вход по почте, Google или Apple, облачная база, синхронизация между устройствами, серверные push-уведомления, шифрование и управление сеансами не подключены. Для этого потребуется отдельный серверный проект, OAuth-настройки и секреты доступа; интерфейс не изображает эти возможности как уже работающие.

Apple Health / Fitness не имеют прямого доступа из обычной PWA к HealthKit. Для обмена предусмотрен ручной импорт XML-файла экспорта Apple Health: поддерживаемые метрики, питание и тренировки сохраняются локально; числовые цели (например, вес) можно обновлять из импортированных данных. Автоматическая синхронизация не выполняется. Внешние календари намеренно не подключены.

## Ограничения уведомлений

Уведомления используют браузерный Notification API и таймеры открытого приложения. Они требуют разрешения браузера; надёжная фоновая доставка, особенно на iOS, не гарантируется без серверного Push-сервиса. На iPhone установите PWA на экран «Домой» и проверьте разрешения уведомлений.

## Проверка

Перед сборкой выполнены проверки синтаксиса JavaScript и Service Worker, валидности JSON-манифеста и браузерные smoke-тесты основных сценариев: создание сущностей, переключение календарных представлений, настройки, Pomodoro, архив/корзина и экспорт. Браузерные тесты выполнялись на встроенном Chromium с загруженными HTML/CSS/JS; фактическое поведение установки и уведомлений дополнительно зависит от браузера и HTTPS-хостинга.
